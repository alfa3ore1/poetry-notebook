# دفتر القصائد | Poetry Notebook

أداة بسيطة لحفظ القصائد العربية والبحث فيها من المتصفح، مع تعديل وحذف وتصدير واستيراد نسخة احتياطية. تعمل محلياً دون حساب أو خادم.

## الاستخدام
افتح `index.html` في متصفح حديث. تحفظ البيانات في تخزين المتصفح على الجهاز ذاته، وقد تُحذف عند مسح بياناته. صدّر نسخة JSON احتياطية بانتظام؛ الاستيراد يستبدل القصائد الحالية.

## المساهمة
نرحب باقتراحات التحسين وطلبات الدمج. هذا مشروع جديد ولا يدّعي وجود مستخدمين أو مساهمات سابقة.
